Observações:
<ul>
  <li>É necessário garantir que a mão direita sempre vai ser detectada primeiro. Essa é uma limitação que foi aplicada para sempre saber qual é a esquerda ou direita considerando sempre a primeira detecção.
  </li>
  <li>O dataset da Microsoft contém arquivos em cada arquivo csv uma sequência ininterrupta de execuções de um gesto, sem a definição de quando uma execução inicia e termina. Tive que fazer um processo manual para separar as sequências. Para realizar tal tarefa foi necessário verificar a partir do Matlab (plotando um gráfico 2d) a frequência contínua das posições para identificar quando ele iniciava e terminava. Assim, com uma posição aproximada, foi possível separar as execuções do arquivo.
  </li>
</ul>
